منجز (Munjiz)
منصة أتمتة استثناءات الجوازات وضمان استمرارية التشغيل — هاكاثون الخدمات الإلكترونية الحكومية 2026، المسار الثالث (الأتمتة والكفاءة التشغيلية).
الفكرة
منجز لا يستبدل أبشر. هو طبقة تنظيمية تعمل فوق الخدمات الحكومية المؤتمتة — تُغلق التعثر تفاعليًا، تمنعه استباقيًا قبل الإرسال، وتُسرّع قرار الموظف بملخص ذكي مصرّح عنه.
المشكلة اللي يعالجها: المعاملة تتعثر بعد أن يكتب النظام الأساسي رمز خطأ داخلي في قاعدة البيانات — لكن لا أحد يشغّل إجراء الإغلاق بعد هذا الرمز. المستفيد يرى "تعذّر التنفيذ" ويبقى منتظرًا حتى الغرامة (بعد 3 أيام) أو "واصل" أو الاتصال بـ 992.
منجز يقرأ رمز التعثر المصنّف، يربط النتيجة بإجراء محدد من جدول القواعد، وإما يُغلق المعاملة آليًا أو يُصعّدها لموظف بملف جاهز.
التقنيات المستخدمة
الطبقة	التقنية
Backend	Python 3 + Flask
قاعدة البيانات	SQLite
Frontend	HTML / CSS / JavaScript (Vanilla)
الرسوم البيانية	Chart.js
الاتصال	REST API + JSON
لا يوجد إطار عمل (framework) للواجهة — التصميم معتمد مسبقًا، والحفاظ عليه يعني عدم الحاجة لأي خطوة بناء (build step).
البنية
munjiz-backend/
├── frontend/
│   └── index.html          الواجهة كاملة (4 تبويبات)
├── src/
│   ├── app.py               نقطة تشغيل Flask
│   ├── config/db.py         الاتصال بقاعدة البيانات
│   ├── seed/seed.py         بناء الجداول + بيانات صناعية واقعية
│   ├── routes/               طبقة الاستقبال (HTTP → JSON)
│   └── services/              طبقة المنطق — كل قرار وحساب هنا
│       ├── resolution_service.py    محرك حل الاستثناءات (قلب النظام)
│       ├── integration_service.py   محاكي تكامل حكومي (Mock)
│       ├── cases_service.py         طابور الموظف + القرارات
│       ├── transactions_service.py  تفاصيل المعاملة
│       ├── beneficiary_service.py   معاملات المستفيد
│       ├── codes_service.py         قاموس أكواد منجز
│       ├── dashboard_service.py     الإحصاءات
│       └── forecast_service.py      التوقع + الاستمرارية
└── data/munjiz.db            تُبنى تلقائيًا عند أول تشغيل
مبدأ الفصل: الـ routes لا تحتوي أي منطق أعمال — فقط استقبال الطلب وإرجاع JSON. كل القرارات تصير داخل services.

التشغيل محليًا
cd munjiz-backend
pip install -r Requirements.txt
python3 src/seed/seed.py
python3 src/app.py
افتحي http://127.0.0.1:5000/.
الواجهات الأربع
لوحة المتابعة — إحصاءات حية، توقع الحمل، حالة الاستمرارية، أقرب فرع أحوال
معاملاتي — معاملات المستفيد المتعثرة + التشخيص + رحلة الطلب
طلبات الموظف — الحالات التي تحتاج قرارًا بشريًا فقط، مع ملخص Copilot
دليل التعثرات — جدول كامل بكل كود وكيفية معالجته

البيانات
كل البيانات صناعية بالكامل (أسماء، منشآت، معرّفات) — يبنيها seed.py من الصفر بكل تشغيل. لا اتصال حقيقي بأي نظام حكومي (أبشر، مقيم، قوى) — طبقة محاكاة موثّقة بوضوح.
